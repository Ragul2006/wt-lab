EXPERIMENT 1: Student Registration Form using HTML

AIM
To create a student registration web page using HTML form controls such as text boxes, radio buttons, checkboxes, drop-down lists and a submit button.

PROCEDURE
1. Create a file named index.html.
2. Add a heading and a form using the <form> tag.
3. Create text boxes for student name, register number and email.
4. Add radio buttons for gender and checkboxes for skills.
5. Add a drop-down list for department.
6. Add a submit button and open the file in a web browser.

PROGRAM FILES

index.html
==========
<!DOCTYPE html>
<html>
<head><title>Student Registration</title></head>
<body>
<h2>Student Registration Form</h2>
<form>
  Name: <input type="text" name="name"><br><br>
  Register Number: <input type="text" name="regno"><br><br>
  Email: <input type="email" name="email"><br><br>
  Gender:
  <input type="radio" name="gender" value="Male"> Male
  <input type="radio" name="gender" value="Female"> Female<br><br>
  Skills:
  <input type="checkbox" name="skill" value="HTML"> HTML
  <input type="checkbox" name="skill" value="CSS"> CSS
  <input type="checkbox" name="skill" value="JavaScript"> JavaScript<br><br>
  Department:
  <select name="department">
    <option>AI and Data Science</option>
    <option>Computer Science</option>
    <option>Information Technology</option>
    <option>Electronics</option>
  </select><br><br>
  <input type="submit" value="Register">
  <input type="reset" value="Clear">
</form>
</body>
</html>

OUTPUT
A registration form is displayed with name, register number, email, gender radio buttons, skill checkboxes, department list and Register/Clear buttons.

RESULT
Thus, the student registration form using HTML form controls was created successfully.
